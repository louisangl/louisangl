## Ce sur quoi je travaille

**GraphRAG — Groupe ADP** *(stage PFE, 7 mois)*  
Pipeline complet d'indexation et de raisonnement sur corpus documentaire aéroportuaire. Architecture hybride Neo4j + pgvector, orchestration ReAct, évaluation automatisée LLM-as-a-judge. Résultat : correctness de 55% à 80% sur des requêtes multi-hop.

**Aircraft Fuel Digital Twin** *(en cours)*  
Jumeau numérique de consommation carburant : ingestion temps-réel via OpenSky Network (ADS-B), modèle physique maison, estimation CO₂ par vol. L'objectif est de coupler les équations de vol à des données réelles pour produire un modèle prédictif calibré.

**Chatbot LLM orienté production** *(en cours)*  
Inférence Groq, observabilité Langfuse, stack MLOps légère. L'objectif est une architecture modulaire réutilisable, pas un prototype.

**PINNs — Physics-Informed Neural Networks** *(exploration)*  
Réseaux contraints par équations différentielles appliqués à des problèmes de dynamique de vol. PyTorch.
