## Projets

**GraphRAG — Groupe ADP** &nbsp;`Stage PFE · 7 mois`  
Pipeline complet sur corpus documentaire aéroportuaire. Architecture hybride Neo4j + pgvector, orchestration ReAct, évaluation LLM-as-a-judge.  
Correctness : **55% → 80%** sur requêtes multi-hop.  
→ [`graphrag-pipeline`](https://github.com/louisangl/graphrag-pipeline)

---

**Aircraft Fuel Digital Twin** &nbsp;`En cours`  
Jumeau numérique de consommation carburant : ingestion ADS-B via OpenSky Network, modèle physique maison (traînée, poussée, masse), estimation CO₂ par vol.

---

**Chatbot LLM orienté production** &nbsp;`En cours`  
Inférence Groq, observabilité Langfuse, stack MLOps légère. Architecture modulaire réutilisable.

---

**PINNs — Physics-Informed Neural Networks** &nbsp;`Exploration`  
Réseaux contraints par équations différentielles appliqués à la dynamique de vol. PyTorch.
